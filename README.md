# FORMA CERAMICA
Готовый многостраничный React + TypeScript + Vite + Tailwind CSS интернет-магазин по предоставленному референсу.

## Запуск
1. `npm install`
2. `npm run dev`
3. Откройте адрес Vite в браузере.

## Страницы
/, /catalog, /product/aria, /collections, /collections/terra, /about, /journal, /journal/how-to-choose-ceramics, /cart, /favorites, /search.

## Функции
React Router, поиск, фильтры, сортировка, избранное, корзина, изменение количества, localStorage, товарные страницы, адаптивное меню и мобильная сетка.

Изображения подключены как большие оригиналы через Unsplash CDN; при необходимости их можно заменить локальными 4K файлами в `src/data/products.ts` и соответствующих страницах.
